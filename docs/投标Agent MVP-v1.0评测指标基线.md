# 投标 Agent MVP-v1.0 评测指标基线

> 更新时间：2026-05-20
> 目的：在没有真实客户数据前，用固定脱敏样本建立可重复的 MVP1.0 质量基线。
> 适用范围：文件解析、合规矩阵、证据推荐、提交前核验、商务/资格草稿、审批导出和审计复盘。

## 1. 基线样本

| 样本 | 用途 | 当前口径 |
| --- | --- | --- |
| `洁净车间净化设备采购与安装项目` | MVP1.0 黄金演示和回归 | 净化/洁净工程方向 canonical demo |
| `净化运维服务托管项目公开招标公告.docx` | 规则兜底抽取质量 | 验证公开公告拆分、去重和污染过滤 |
| `智慧园区弱电工程投标` | 通用链路兼容回归 | 保证原通用样本不被净化方向改动破坏 |

真实客户数据进入前，所有指标只作为工程质量基线，不代表真实项目准确率承诺。

## 2. P0 指标

| 指标 | 定义 | 黄金样本目标 |
| --- | --- | --- |
| 必需项覆盖 | 资格、强制、截止时间、技术响应、评分项是否被识别 | 五类矩阵项均存在 |
| 矩阵重复率 | 归一化后相同要求重复出现的比例 | 净化运维公告为 0 |
| 拆分粒度 | 复合资格条款是否拆到可处理粒度 | 资质、证书、项目经理、B 证、联合体、信用、小微企业应独立可见 |
| 污染项率 | 公告标题、下载地址、联系方式等非要求内容进入矩阵的比例 | 明显标题/联系信息不得进入矩阵 |
| 来源覆盖 | 关键矩阵项是否有来源版本、来源分块和原文 | 黄金样本关键矩阵项 100% 有来源 |
| 证据推荐可解释 | 候选资料是否返回推荐原因、命中词和资料状态 | 检测报告/产品目录/技术方案均可解释 |
| 提交前阻塞命中 | 高风险未确认、强制项缺证据、草稿无法核验事实是否进入 preflight `block` | 均必须阻塞或进入阻塞摘要 |
| 风险接受留痕 | 阻塞状态下审批/导出是否要求说明并保存快照 | 必须保存 preflight 快照和说明 |
| 异步可见性 | 上传新建后解析/矩阵后台状态是否可见 | `pending/running/succeeded/failed` 均有可理解文案 |

## 3. 自动化检查命令

快速黄金样本回归：

```bash
make mvp1-golden
```

完整 MVP1.0 本地检查：

```bash
make mvp1-check
```

## 4. 试用前通过标准

- `make mvp1-golden` 必须通过。
- `make mvp1-check` 必须通过，除非失败项被明确记录为环境问题。
- 手工演示路径必须能连续跑完，不依赖开发者手工改数据库。
- 任何 P0 问题必须记录到种子用户问题记录表，不得只在聊天或口头沟通中保留。

## 5. 后续真实数据进入后的新增指标

真实/脱敏客户样本进入后，再补充以下指标：

- 资格/强制项人工标注召回率。
- 截止时间、开标时间、保证金、格式要求等关键字段准确率。
- 证据推荐 Top-3 命中率。
- 草稿人工大改率。
- 阻塞项误报/漏报率。
- 单项目从导入到第一版可审阅矩阵的耗时。
