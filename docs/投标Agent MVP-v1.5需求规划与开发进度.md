# 投标 Agent MVP-v1.5 需求规划与开发进度

> 更新时间：2026-06-06
> 当前阶段：规划中，待 MVP1.4 易用性优化落地后启动
> 版本定位：企业资料 RAG、Embedding/Rerank 和候选证据推荐，作为 ContextPack 的上游证据增强。
> 版本沿革：原 MVP1.4 的 RAG 证据增强规划，因易用性优化插入为 MVP1.4，整体顺延为 MVP1.5。

## 1. 版本目标

MVP1.5 的目标是把“人工找证据”升级为“系统推荐候选证据，人工确认后使用”。它不直接生成正式标书，也不替用户自动绑定证据。

本版本要解决：

1. 从企业资料库召回证照、人员、业绩、承诺、历史材料等候选证据。
2. 使用关键词检索、元数据过滤、pgvector 向量召回和 rerank 提升候选质量。
3. 给出命中片段、推荐理由、资料状态、权限和风险提示。
4. 用户确认后，证据进入 `bound_evidence`，再由 MVP1.2 ContextPack 和 MVP1.3 草稿链路消费。

## 2. 核心原则

1. RAG 是候选证据增强器，不是自动决策器。
2. 候选证据必须人工确认后，才能进入 ContextPack。
3. 检索结果必须带来源、页码、片段、权限、有效期和推荐理由。
4. 低置信度、权限不足、过期或冲突材料只能提示风险，不能自动绑定。
5. RAG 不可用时，手工证据绑定和 ContextPack 主链路仍应可用。

## 3. 不纳入 MVP1.5

以下能力不进入 MVP1.5：

1. 技术标核心章节生成。
2. 净化产品选型、参数匹配和候选配置。
3. 图纸/示意图辅助。
4. OCR 和复杂补遗版本链。
5. 多 Agent 编排。
6. 报价辅助、自动报名、自动签章和自动提交。
7. 未经人工确认的自动证据绑定。
8. 自动判断企业资质、人员、业绩真实性。

## 4. 主流程

1. 用户在矩阵项、资格项、缺证据项或 ContextPack 缺项上点击“推荐证据”。
2. 系统构建检索查询，包含条款文本、条目类型、项目地区、资料类型、权限和有效期约束。
3. 系统执行关键词检索、元数据过滤和向量召回。
4. 系统使用 rerank 对候选片段重排。
5. 系统展示候选证据、命中片段、推荐理由、风险和权限状态。
6. 用户绑定、拒绝或标记待补。
7. 已绑定证据进入 ContextPack 的 `bound_evidence`。
8. 被拒绝或低置信度候选进入评测样本和审计日志。

## 5. 需求范围

### P0：索引与候选证据推荐

| 模块 | 需求 | 状态 | 说明 |
| --- | --- | --- | --- |
| 资料切片标准化 | 对企业资料按页码、段落、表格和资料类型生成 chunk | 未开始 | 复用现有企业资料模型 |
| Embedding 接入 | 接入中文 embedding 模型 | 未开始 | 模型可配置，失败可降级 |
| pgvector 索引 | 建立向量字段、索引和重建任务 | 未开始 | 支持企业级和项目级过滤 |
| 混合检索 | 关键词、元数据过滤和向量召回组合 | 未开始 | 不只依赖语义相似度 |
| Rerank 接入 | 对候选片段重排并输出原因 | 未开始 | 支持降级返回未重排结果 |
| 候选证据接口 | 按矩阵项返回候选材料、片段和理由 | 未开始 | 默认不自动绑定 |
| 人工绑定/拒绝 | 用户确认后绑定证据，拒绝原因写审计 | 未开始 | 反哺评测集 |

| 模块 | 需求 | 状态 | 说明 |

## 6. 异常处理和收敛规则

| 场景 | 系统处理 | 是否允许自动绑定 |
| --- | --- | --- |
| 无检索结果 | 标记待补资料，保留人工上传入口 | 不允许 |
| 低置信度结果 | 展示为弱候选，提示人工核验 | 不允许 |
| 资料过期 | 标记过期风险，建议替换材料 | 不允许 |
| 权限不足 | 不展示敏感片段或仅显示脱敏摘要 | 不允许 |
| 索引过期 | 提示重建索引，候选结果标记过期 | 不允许 |
| Embedding 服务失败 | 降级关键词和元数据检索 | 不允许 |
| Rerank 服务失败 | 返回未重排候选并提示降级 | 不允许 |
| 候选与条款冲突 | 标记冲突原因，进入人工确认 | 不允许 |
| 同一证据重复命中 | 合并展示来源和命中原因 | 不允许 |

## 7. 验收标准

1. 企业资料可以完成索引重建，并展示索引版本、覆盖率和失败 chunk。
2. 指定合规矩阵项后，系统能返回候选证据、来源片段、资料状态和推荐理由。
3. 候选证据默认不自动绑定，必须由用户确认。
4. 权限不足、敏感、过期和低置信度材料不会进入可直接引用证据。
5. Embedding 或 rerank 不可用时，系统能降级并明确提示。
6. 绑定后的证据能进入 MVP1.2 ContextPack 的 `bound_evidence`。
7. 拒绝和替换候选证据会记录原因。
8. 固定评测样本能输出召回率、TopK 命中率、人工绑定率和误推荐类型。
