# 投标 Agent MVP-v1.0 需求规划与完成度

> 更新时间：2026-05-25
> 范围基线：MVP-v1.0 先完成通用投标辅助闭环，并在数据、页面和样本上向净化设备/洁净工程方向靠拢
> 阶段目标：在 MVP-v0.5 已完成的“建项目 → 获取/上传文件 → 解析 → 合规矩阵 → 人工处理 → 导出矩阵快照 → 审计留痕”基础上，完成可演示、可试用的通用投标辅助闭环；MVP1.1 已实际收口为模型安全接入、合规矩阵 AI 增强和原文审阅纠错，净化设备完整行业闭环和多 Agent 拆分继续顺延。

## 1. v1.0 产品边界

MVP-v1.0 的核心目标仍然是通用投标辅助闭环：读标、合规矩阵、企业资料、资格预评估、商务/资格响应草稿、事实校验、审批、导出和审计。

同时，v1.0 不再把后续方向放在“全行业规则库”，而是明确向净化设备/洁净工程意向客户靠拢：

- 示例数据优先使用净化设备/洁净工程类项目。
- 企业资料库预留产品目录、设备参数、检测报告、历史方案等资料类型。
- 技术要求抽取先做通用“技术响应要求/评分项/待确认项”，不做完整行业选型。
- 技术标书正文和图纸不进入 v1.0 闭环，只预留数据和页面位置。

初始版本的能力边界如下：

| 能力 | v1.0 是否支持 | 说明 |
| --- | --- | --- |
| 通用项目导入和读标 | 支持 | 支持手工创建、文件/网页/公开链接导入，并抽取项目基础信息 |
| 文件、解析和版本 | 支持 | 支持 Word/PDF 基础解析、解析分块查看、人工修正和版本化 |
| 合规矩阵 | 支持 | 抽取资格要求、强制项、评分办法、技术响应要求和风险项 |
| 企业资料库 | 支持 | 支持资质、人员、业绩、商务模板、授权材料；预留产品资料类型 |
| 资格预评估 | 支持 | 根据合规矩阵和企业资料生成满足、不满足、待确认、缺材料和 Go/No-Go 建议 |
| 商务/资格草稿 | 支持 | 生成可核验的商务标/资格响应章节草稿，支持人工编辑和 Word 导出 |
| 事实性校验 | 支持 | 校验项目名、人员、证书编号、金额、日期等事实，无法验证内容标记人工确认 |
| 审批与人工关口 | 支持 | 支持资格确认、章节确认、提交确认；提交前阻塞项需填写风险接受说明 |
| 提交前核验 | 支持 | 汇总版本、风险、证据、草稿事实、审批和关键日期风险 |
| 关键字段确认 | 支持 | 项目/标段基础字段可编辑、可审计，用于提交前核验和复盘 |
| 净化设备行业靠拢 | 支持预埋 | 预留产品资料、技术要求、示意图、技术章节等后续能力入口，并新增净化方向脱敏演示样本 |
| 净化设备完整行业闭环 | 不进入 v1.0 | 产品选型、投标示意图、技术标核心章节生成进入长期规划 |
| 多 Agent 拆分 | 不进入 v1.0 | 读标 Agent、图纸 Agent、技术标 Agent 等进入长期规划 |
| 报价文件 | 暂不支持 | 仅保留报价风险提示和人工确认边界 |
| 自动签章/自动提交 | 不支持 | 系统只做辅助生成、检查、提醒和留痕，最终提交必须人工完成 |

## 2. 状态定义

| 状态 | 含义 |
| --- | --- |
| 已完成 | 已有后端能力、前端入口或测试验证，能按 v1.0 对应口径使用 |
| 部分完成 | 已有基础能力，但还缺核心业务逻辑、前端闭环、审计、测试或数据模型 |
| 未开始 | 尚未形成可用实现 |
| 长期规划 | 不进入 v1.0/1.1，也不排入具体 MVP 版本，待样本、数据和责任边界明确后再拆专项 |

按调整后的 v1.0 范围统计，通用投标闭环已基本成型；净化设备行业能力只保留资料类型、入口和样本方向预埋，完整行业闭环进入长期规划。

| 状态 | 数量 | 说明 |
| --- | ---: | --- |
| 已完成 | 18 | v0.5 基础能力 + v1.0 P0 商务标、事实校验、Go/No-Go、审批、基础资料检索、模型调用审计、矩阵证据解释、解析版本增强、企业画像偏好和禁投策略第一版、净化资料类型预埋、技术响应入口、流程助手 UI、提交前核验闸口、关键字段确认和净化演示样本 |

| 未开始 | 0 | v1.0 P0 主链路均已有可运行第一版或明确复用底座 |
| 长期规划 | 3 | 地方/行业规则包完整机制、净化设备完整行业闭环、多 Agent 拆分；其中行业闭环包含产品选型、投标示意图和技术标核心章节 |

当前判断：

- v0.5 的基础文件解析、合规矩阵和审计闭环已经完成。
- v1.0 已完成企业资料库、资格预评估、资料检索与矩阵证据绑定、商务标草稿、事实性校验、Go/No-Go 总体建议和简单审批的第一版闭环。

## 5. v1.0 验收标准

MVP-v1.0 的验收以通用投标辅助闭环为准，并要求演示样本尽量向净化设备/洁净工程靠拢。

| 验收项 | 目标 |
| --- | --- |
| 样本项目 | 固定净化方向脱敏样本 `洁净车间净化设备采购与安装项目`，并保留通用样本用于兼容回归 |
| 项目导入 | 可从文件或网页导入项目，预览抽取结果并确认建项 |
| 关键字段确认 | 可编辑项目/标段关键字段，缺失字段能被提示，修改动作写入审计 |
| 文档解析 | 可查看和搜索解析分块，支持人工修正并发布新版本 |
| 版本过期提醒 | 解析版本更新后，旧矩阵能提示过期并引导重新生成 |
| 合规矩阵 | 生成资格、强制项、评分办法、技术响应要求和风险项，且可回链原文并按处理优先级排序 |
| 企业资料 | 可维护资质、人员、业绩、商务模板、授权材料，并预留产品资料类型 |
| 证据推荐 | 企业资料检索返回推荐原因、命中词、资料状态和证据摘录 |
| 资格预评估 | 可生成满足、不满足、待确认、缺材料和 Go/No-Go 建议 |
| 证据绑定 | 可从企业资料检索候选证据并绑定到矩阵项 |
| 商务/资格草稿 | 可生成、编辑、事实校验并导出 Word；阻塞状态导出需填写风险接受说明并标记内部草稿 |
| 提交前核验 | 工作台显示 `pass` / `warn` / `block`，审批和导出前展示阻塞摘要 |
| 审批与审计 | 资格确认、章节确认、提交确认均有审批任务、阻塞快照、风险接受说明和审计记录 |
| 安全边界 | 文件/网页导入明确为非可信输入，系统不自动审批、自动签章或自动提交 |
| 净化方向预留 | 文档和页面明确产品选型、图纸和技术标章节进入长期规划，不排入具体 MVP |
| 试用前 P0 回归 | `make mvp1-golden` 和 `make mvp1-check` 可重复验证黄金样本、矩阵质量、后端测试和前端构建 |

## 6. 已完成实施切片

### 第一阶段：通用闭环收尾

优先级：P0。

目标是把当前已完成的通用能力打磨成稳定可演示版本。

完成情况：

1. 已完成导入、解析、矩阵、企业资料、资格评估、商务草稿、审批和导出的主链路。
2. 已补齐关键接口测试，后端测试通过。
3. 已统一矩阵项来源、风险解释、证据引用、处理优先级和审计日志展示。
4. 已补充提交前核验、审批阻塞摘要和导出风险说明。

### 第二阶段：净化方向预埋

优先级：P0。

目标是让 v1.0 看起来不是泛泛平台，而是已经准备向净化设备行业收敛。

完成情况：

1. 已在企业资料类型中预留产品资料、检测报告、产品图片、历史方案。
2. 已在技术响应矩阵中保留技术要求、评分项、待确认和风险字段。
