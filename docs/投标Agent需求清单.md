# 投标 Agent 需求清单

> 版本：v0.3
> 日期：2026-06-06
> 目标：形成全量需求池，并冻结 MVP-v0.5 范围用于后续架构质量分析和迭代计划。

## 1. 产品定位

本项目建设一个面向中国招投标业务场景的专业投标 Agent 平台。系统不是“无人值守自动投标”，而是“强辅助、有限执行、人机协同、全程留痕”的投标工作平台。

核心原则：

- 证据优先：所有关键结论必须能回链到招标文件、企业资料、法规规则或历史案例。
- 规则先行：强制项、资质有效期、格式要求、合规红线优先由规则引擎校验。
- 人工关口：参标决策、资格真实性、报价、关键承诺、签章、最终提交必须人工确认。
- 项目隔离：按组织、项目、标段、文件、角色隔离数据、上下文和权限。
- 全程审计：记录上传、解析、检索、生成、修改、审批、导出和提交前检查动作。

## 2. 用户角色

| 角色 | 主要诉求 |
| --- | --- |
| 管理员 | 用户、组织、权限、模型、规则、系统配置管理 |
| 业务负责人 | 判断是否参标、跟踪项目进度、确认商务关键事项 |
| 标书编辑 | 解析招标文件、维护合规矩阵、生成和编辑标书章节 |
| 资质管理员 | 维护证照、人员、业绩、资质材料，处理资格缺项 |
| 法务/合规 | 复核强制条款、合规风险、承诺风险和证据链 |
| 财务/报价 | 参与报价测算、报价风险提示和最终报价确认 |
| 项目经理 | 补充技术方案、项目经验、实施计划和履约能力材料 |
| 授权提交人 | 执行提交前检查、确认签章和最终提交 |
| 审计人员 | 查看审计日志、版本记录、模型调用和审批链路 |

## 21. 建议 MVP 分层范围

### 21.1 MVP-v0.5：最小可用原型

状态：**范围冻结**。后续新增需求默认进入 MVP-v1.0 或二期，除非明确发起范围变更。

目标是在最短周期内验证“招标文件解析到合规矩阵”的核心价值，不追求完整 Agent 闭环。

建议范围：

1. 手工创建项目和标段。
2. 上传招标文件，或通过公开资源站点链接获取招标文件附件。
3. 记录招标文件来源，包括本地上传、公开链接、资源站点名称、原始 URL、获取时间。
4. 基础文档解析，优先支持可复制 PDF 和 Word。
5. 抽取资格要求和强制响应项。
6. 生成基础合规矩阵。
7. 矩阵支持人工确认、人工修改、责任人标记和风险标记。
8. 高风险项必须逐条确认。
9. 导出 Excel 合规矩阵。
10. 基础审计日志。

暂不包含：

- 自动公告批量抓取和机会订阅。
- 复杂资源站点登录、验证码、自动报名、CA/UKey、付费下载和非公开附件获取。
- 企业知识库和 RAG。
- 标书章节生成。
- 完整审批流。
- 报价辅助。
- 复杂地方规则包管理。
- 智能助手执行类动作。

### 21.2 MVP-v1.0：通用投标闭环 + 净化设备方向预埋

目标是在 v0.5 基础上完成可演示、可试用的通用投标辅助闭环，同时在资料类型、技术响应、样本数据和页面入口上向净化设备/洁净工程意向客户靠拢。

MVP-v1.0 不做完整净化行业闭环，也不做多 Agent 拆分。MVP-v1.1 先完成模型安全接入、合规矩阵 AI 增强和原文审阅纠错闭环；净化设备产品选型、投标示意图、技术标核心章节和多 Agent 编排不排入具体 MVP 版本，进入长期规划专项。

建议范围：

1. 系统首页和项目工作台基础交互，继续支持文件、矩阵、资料、草稿、审批和审计。
2. 招标项目信息录入、公告/招标文件抽取和项目基础信息识别。
3. 企业画像、资质材料、人员材料、业绩案例和商务/资格响应底座。
4. 项目、标段、招标文件、附件、企业资料上传和对象存储；预留产品资料、检测报告、历史方案等资料类型。
5. 招标文件解析、解析版本管理、人工修正和矩阵重生成。
6. 资格要求、强制项、评分办法、技术响应要求和风险项抽取。
7. 合规矩阵生成、筛选、批量操作边界、证据回链、规则解释和风险解释。
8. 企业私有资料导入、基础资料检索、证据绑定和数据等级过滤；真实 pgvector RAG 进入 MVP1.5。
9. 商务标书/资格响应章节草稿生成、事实性校验、人工编辑和 Word 导出。
10. 参标资格预评估、Go/No-Go 建议、资格确认和人工审批。
11. 技术响应靠拢：v1.0 识别技术要求、评分项、风险项和待确认项，但不生成完整技术标章节。
12. 净化方向预埋：示例数据、资料类型、页面文案和后续 schema 设计优先面向净化设备/洁净工程。
13. 简单审批任务，支持资格确认、商务章节确认和提交前确认。
14. 智能助手基础 UI、快捷指令、主动提醒和操作日志；真实 Agent 化问答进入长期规划。
15. 审计日志、模型调用记录、证据引用记录、导出 Word/Excel。

不纳入 MVP-v1.0：

1. 净化设备完整行业闭环，包括产品选型、参数匹配、投标示意图和技术标核心章节。
2. 多 Agent 拆分，包括读标 Agent、合规检查 Agent、产品选型 Agent、图纸 Agent、技术标书 Agent 等。
3. 全行业规则库。
4. 正式施工图、CAD 深化图、图纸盖章和工程设计责任。
5. 报价测算、报价决策、自动签章和自动提交。
6. 复杂资源站登录、验证码、CA/UKey 和付费下载。

### 21.3 MVP-v1.1：模型安全接入 + 合规矩阵 AI 增强 + 原文审阅纠错

状态：**P0 + P1 主体开发已完成**。

目标是在 v1.0 通用闭环基础上，让 AI 进入受控的读标、拆分、分类、解释和审阅纠错任务，而不是直接进入技术标生成、多 Agent 或自动决策。

已完成范围：

1. 模型配置中心：支持配置 Chat/LLM 的 `base_url`、`api_key`、`simple_model`、`complex_model`、启用状态和超时。
2. API Key 后端加密存储，前端只展示脱敏值，配置变更和测试连接写审计。
3. PromptOps registry：prompt 版本、hash、schema 和回归测试。
4. 合规矩阵 AI 抽取增强：规则预清洗、模型拆分/分类、schema 校验、规则复核和降级保护。
5. 模型输出必须带来源 chunk、来源摘录、分类理由、拆分理由、置信度和人工复核提示。
6. 污染过滤：公告标题、项目编号、联系方式、采购人/代理机构信息不得进入矩阵。
7. 矩阵审阅视图：左右对照招标文件原文 chunk 和合规条目，支持定位、过滤和确认进度。
8. 人工划选补漏：从原文新增合规项并保留 chunk、选中文本和 offset。
9. 相似补票：新增条目后提示全文相同/相近片段并逐个确认。
10. 文本 Diff 高亮：展示相似片段中的新增、缺失和替换内容。
11. 重复项关联与级联确认：疑似重复只提示，人工确认同组后才同步确认状态。
12. 高风险、强制项、资格项确认防误触：必须核对原文并填写依据。

不纳入 MVP-v1.1：

1. 企业资料真实 pgvector RAG。
2. Embedding/Rerank 调用链。
3. 技术标核心章节生成。
4. 净化设备产品选型和参数匹配。
5. 投标示意图或正式设计图。
6. 多 Agent 编排和 Agent 输入输出 schema 平台化。
7. 报价、OCR、自动报名、自动签章和自动提交。

### 21.4 MVP-v1.2、MVP-v1.3、MVP-v1.4、MVP-v1.5 与长期规划

MVP-v1.2 聚焦商务/资格生成 ContextPack：

1. 商务/资格生成上下文包预览。
2. ContextPack readiness pass/warn/block 和处理动作。
3. 资格预评估与参标建议确认门禁。
4. 已绑定证据、缺事实和风险记录快照。
5. SectionContextPack 章节上下文确认。

MVP-v1.3 聚焦基于 ContextPack 的商务/资格草稿生成闭环：

1. 分章节提示词和输出 schema。
2. 结构化商务/资格生成稿。
3. DraftBlock 与矩阵项、证据、原文的回链。
4. 生成稿左右对照审阅。
5. 覆盖检查、事实校验和 Word 导出前风险快照。

MVP-v1.4 聚焦易用性优化（首页治理、术语白话化、审阅提效、等待体验、管理看板），不扩 AI 能力边界。

MVP-v1.5 聚焦企业资料真实 RAG 和候选证据推荐：

1. pgvector + `BAAI/bge-large-zh-v1.5` embedding。
2. `BAAI/bge-reranker-large` 重排。
3. 企业资料索引重建和证据推荐解释增强。
4. 企业资料与招标要求语义匹配。
5. 候选证据人工绑定后进入 ContextPack。

长期规划不排入具体 MVP 版本，待样本、数据、专业责任和交付边界明确后再拆专项：

1. 净化行业知识包和客户产品目录。
2. 净化技术参数匹配、技术偏离分析和候选配置。
3. 检测报告、产品目录和历史方案绑定到技术响应项。
4. 技术标书核心章节草稿。
5. 投标阶段示意图辅助。
6. 多 Agent 编排和 Agent 级审计。
7. OCR、复杂补遗版本链和报价辅助。
8. 自动报名、自动签章和自动提交不做模型自动执行；如未来进入系统，只能作为人工审批后的受控外部集成评估。
