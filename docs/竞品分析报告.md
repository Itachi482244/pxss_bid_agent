> 更新日期：2026-05-24

> 分析目标：明确市场格局、识别差距、指导产品优先级

---

## 1. 市场概况

### 1.1 政策背景

2026 年 2 月，国家发改委等八部门联合印发《关于加快招标投标领域人工智能推广应用的实施意见》（发改法规〔2026〕195 号），从政策层面推动 AI 在招投标全流程深度应用。2026 年被视为 **"AI+招投标"政策落地元年**。

### 1.2 市场趋势

| 趋势 | 说明 |
|------|------|
| **行业垂直化** | 从通用 AI 助手进化为行业垂直 Agent，强调业务理解深度 |
| **多智能体架构** | 多家头部产品采用多 Agent 协同架构，替代串行处理流程 |
| **合规是第一竞争力** | 废标风险识别和查重防控成为核心壁垒 |
| **私有化部署刚需** | 央国企客户对数据安全高度敏感，本地化部署是入场条件 |
| **从辅助到策略** | 从文档生成进化为全流程智能决策支持 |

## 3. 产品详析

### 3.1 钛投标AI（景网数据）

**核心能力：**

- **技术栈**：自研数字方案爵士大模型 + 阿里云千问 Max + 火山引擎 ArkClaw
- **架构**：5 个原子 Skills（招标解析、标书生成、标书美化、标书检查、标书查重）
- **功能**：招标文件解析（3 分钟百页）、全场景标书生成（20 分钟千页）、32 类 300+ 合规风控、三维原创查重、暗标排版、多模态图文生成

**数据表现：**

| 指标 | 数据 |
|------|------|
| 关键条款识别准确率 | 98% |
| 废标风险识别率 | 99.8% |
| 合规率 | 99%+ |
| 标书制作周期 | 5 天 → 0.5 天 |
| 标书重复率 | 1.8% |

**多模态能力：** 2026 年重点拓展多模态生成，支持施工图纸、系统架构图、流程图与文本自动融合。但以"导入已有图纸+AI 识别优化"为主，非从零生成 CAD 图纸。

**定价：** 基础版 6,000 元/年、专业版 15,000 元/年、尊享版 35,000 元/年

**优势：** 行业覆盖广、落地客户多、合规能力成熟、三维查重独特

**劣势：** 偏通用模板拼接，缺少垂直行业深度适配；图纸能力为"识别+复用"而非"生成"

---

### 3.2 云境标书AI（深入云境）

**核心能力：**

- **技术栈**：LLM + RAG + 知识图谱 + 多模态
- **功能**：百页文件 1 分钟解析（≥200 要素、≥99% 准确率）、单分钟生成 3 万字、支持 5000 页+ 超大文档、32 类废标风控（≥99%）、三层防重网络（重复率 <3%）、智能图表生成（流程图/进度表/组织架构图/对比图等）、图文混排

**数据表现：**

| 指标 | 数据 |
|------|------|
| 招标文件解析速度 | 百页 ≤ 1 分钟 |
| 关键要素识别 | ≥200 个，准确率 ≥99% |
| 生成速度 | 3 万字/分钟 |
| 得分点响应率 | ≥99% |
| 标书重复率 | <3% |
| 废标风险识别 | 32 类，准确率 ≥99% |

**多模态能力：** 支持智能生成施工流程图、组织架构图、进度表、技术方案对比图等；支持全网搜图并插入；工程量清单解析。属于 **PPT 级图表自动生成**，非 CAD 级。

**定价：** 核心功能永久免费（解析+大纲）；新人送 10 万字；月卡 88 元

**优势：** 性价比极高、生成速度快、防重能力强、工程建设行业适配

**劣势：** 缺少垂直行业深度知识库，流程图为通用模板，非工程专业图纸

---

### 3.3 投标大王2.0（华胜天成）

**核心能力：**

- **技术栈**：多智能体协同 + 思维链 + 多模型
- **功能**：招标文件解读、资源匹配、智能资源库、投标文件核查与响应分析、标书智能编写（一键生成大纲+完整初稿）、行业知识库自我优化

**数据表现：**

| 指标 | 优化前 | 优化后 |
|------|--------|--------|
| 招标文件解读 | 1 天 | **10 分钟** |
| 投标文件审查 | 4 天 | **2 小时** |
| 标书撰写 | 1 周 | **1 天** |
| 中标率 | 17% | **63%** |

**优势：** 央企落地验证、多智能体架构成熟、中标率提升可量化

**劣势：** 产品偏重文字生成，未明确提及图表/图纸能力

---

### 3.4 招采Claw（科大讯飞）

**核心能力：**

- **技术栈**：AstronClaw（智能体平台）+ SkillHub（技能库）+ 招采知识库
- **架构**：Agent Team——初评阶段每家供应商独立 Agent；详评阶段商务/技术/报价 Agent 协同
- **功能**：招标文件编制、合规性审查、投标异常行为检测（围标/串标）、辅助评标、自然语言交互

**核心亮点：** 多供应商/多条款并发审查、全程 AI 驱动 + 人工关键节点确认、评审依据可追溯（评分依据+推理思维链+原文定位）

**部署：** 全面支持私有化部署，数据留存企业内网

**优势：** 讯飞品牌背书、AI 能力底座强、Agent Team 架构独特、评审场景深度

**劣势：** 偏采购方/招标方视角，投标方能力相对弱；刚发布，产品成熟度待验证

---

### 3.5 Altura（国际化参考）

**核心能力：**

- **架构**：Bid Companion（对话式 AI Agent）+ Knowledge Fabric + 自治 AI Agent
- **功能**：30+ 文档同时对话、投标知识搜索、标书草稿生成、中标/输标分析、机会识别与获取、Bid/No-Bid 决策支持、Product Matcher（50+ 产品/秒自动匹配）

**关键差异点：**

1. **自治 Agent 理念**——Agent 不只是辅助，而是自主完成任务：自动草拟应答、自动标记风险、自动挖掘投标机会
2. **Knowledge Fabric**——每次投标数据反哺知识网络，越用越"懂"企业
3. **Bid/No-Bid 决策引擎**——可配置评分标准 + 风险评分，用数据辅助决策
4. **Product Matcher**——50+ 产品/秒匹配招标要求

**融资：** €8M Series A（Octopus Ventures），2025.06 收购德国 Tendara

**借鉴意义：** Knowledge Fabric（知识反哺）、自治 Agent（非被动应答）、Product Matcher（与你们规划的净化设备选型场景高度相关）

## 6. 启示与建议

### 6.1 战略定位建议

基于竞品分析，建议产品定位为：

> **"最懂中国招投标规则的智能工作台 + 最懂净化行业的技术标大脑"**

两层定位对应不同竞争维度：
- **工作台层**（通用底座）：解析、矩阵、审计、证据链——在通用赛道对标竞品，不丢分
- **行业层**（垂直壁垒）：净化行业技术标、参数匹配、设备选型、CAD 初稿——在垂直赛道拉开差距

### 6.2 优先级建议

| 阶段 | 核心任务 | 要追赶的能力 | 要建立壁垒的能力 |
|------|---------|------------|----------------|
| **MVP1.1（当前）** | 模型配置+AI 读标增强 | — | 合规矩阵精细化、证据链 |
| **MVP1.2** | ContextPack+商务/资格草稿增强 | 评分点对齐、商务/资格稿生成链路 | 事实校验、证据绑定 |
| **MVP1.3** | RAG+候选证据推荐 | 知识库 RAG、向量检索、证据推荐 | 企业资料检索质量、人工绑定闭环 |
| **长期规划** | 净化垂直与技术标增强 | 技术标章节、参数匹配 | 净化专用知识库、设备选型、**CAD 初稿** |

### 6.3 值得关注的国际化参考

1. **Altura 的 Product Matcher**：50+ 产品/秒匹配招标要求——与你们规划的"净化设备选型"高度相似，建议研究其实现思路
2. **Altura 的 Knowledge Fabric**：数据反哺知识网络——你们的企业资料库也可以朝这个方向演进
3. **TrunkBid 的 Scope Gap 检测**：建筑工程投标中自动识别范围差距——可以扩展到净化行业材料清单/设备清单的完整性检查

### 6.4 量化指标建议

建立产品 Benchmark 指标集，为后续营销准备数据：

|------|------|------|

| 条款识别覆盖率 | ≥ 98% | 对标钛投标 |
| 矩阵项去重率 | ≥ 95% | — |

| 人工确认节省时间 | — | 需测算 |
