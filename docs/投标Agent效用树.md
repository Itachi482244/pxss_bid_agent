# 投标 Agent 效用树

> 版本：v0.1
> 日期：2026-05-14
> 范围：围绕已冻结的 MVP-v0.5，兼顾 MVP-v1.0 与 SaaS 生产化风险。

## 1. 说明

效用树用于把架构质量目标拆成可讨论、可排序、可验收的具体场景。

标记说明：

- 重要性：H 高，M 中，L 低。
- 风险：H 高，M 中，L 低。
- 阶段：v0.5、v1.0、生产化。

优先处理原则：

- `H/H`：必须优先处理，是架构驱动因素。
- `H/M`：MVP 阶段需要明确方案。
- `M/H`：容易出事故，至少要有边界和缓解策略。
- `M/M` 以下：可以后续迭代。

## 3. 叶子场景排序

| 编号 | 质量属性 | 叶子场景 | 阶段 | 重要性 | 风险 | 架构策略 |
| --- | --- | --- | --- | --- | --- | --- |
| UT-001 | 安全性 | SaaS 用户查询项目、文件、矩阵时，只能访问本租户和授权项目数据 | v0.5 | H | H | 安全策略组件统一注入租户、项目 ACL、数据等级过滤 |
| UT-002 | 安全性 | 用户通过公开链接获取招标文件时，系统防止 SSRF、超大文件和恶意协议 | v0.5 | H | H | 链接校验、协议白名单、域名策略、大小限制、超时、Content-Type 检查 |
| UT-003 | 审计性 | 用户修改矩阵项时必须填写修改原因，记录前后差异 | v0.5 | H | H | 矩阵修改接口强制 reason 字段，审计表结构化存储 before/after |
| UT-004 | 可追溯性 | 每个合规矩阵项能回链到招标文件、版本、页码或原文片段 | v0.5 | H | H | 文档 chunk、矩阵 source 字段、文件版本关联 |
| UT-005 | 可靠性 | 文档解析失败后可查看原因并重试，不产生重复矩阵项 | v0.5 | H | M | 异步任务状态机、幂等键、失败原因持久化 |
| UT-006 | 审计性 | 从资源站点获取招标文件时记录原始 URL、资源站点、下载时间和文件哈希 | v0.5 | H | M | 文件元数据和审计事件双记录 |

| UT-009 | 安全性 | 文件下载只能通过短期授权链接，不能暴露对象存储永久地址 | v0.5 | H | M | 后端签发短期 URL，下载事件审计 |

## 4. MVP-v0.5 架构驱动场景

MVP-v0.5 必须优先覆盖以下 `H/H` 或高影响场景：

| 编号 | 场景 | 必须落地的架构机制 |
| --- | --- | --- |
| UT-001 | SaaS 查询租户隔离 | 所有表带 tenant_id/project_id；查询统一走策略组件或服务层过滤 |
| UT-002 | 公开链接获取文件安全 | URL 校验、协议限制、文件大小限制、下载超时、Content-Type 检查 |
| UT-003 | 矩阵修改审计 | 修改原因、前后差异、操作者、时间写入审计日志 |
| UT-004 | 矩阵项证据回链 | 文档版本、页码、chunk、原文片段保存到矩阵项 |
| UT-005 | 解析失败可恢复 | 异步任务表、任务状态机、失败原因、幂等键 |
| UT-007 | 抽取结果来源约束 | 无来源结果进入待确认，不自动进入已确认状态 |
| UT-009 | 文件短期授权链接 | 对象存储通过后端授权访问，不暴露永久地址 |
| UT-017 | 下载和解析异步化 | API 只创建任务，Worker 执行下载、解析、导出 |

## 5. MVP-v0.5 可接受折中

| 折中项 | 决策 | 原因 |
| --- | --- | --- |
| 地方规则包 | 只预留规则字段和接口，不做复杂管理后台 | v0.5 聚焦解析到矩阵闭环 |
| RAG | 暂不做 | 避免知识库、向量索引和权限过滤扩大范围 |
| 智能助手 | 暂不做执行类动作 | 降低安全和审计复杂度 |
| 报价 | 暂不做 | 报价涉及高风险审批和版本管理 |
| 自动公告抓取 | 暂不做批量抓取，只做手工公开链接获取文件 | 避免验证码、登录、平台差异和合规问题 |
| 双人复核 | 状态机预留字段，不实现完整流程 | 保留扩展点，降低 MVP 工作量 |

## 6. 质量属性到架构决策映射

| 质量属性 | 关键架构决策 |
| --- | --- |
| 安全性 | 安全入口网关、策略组件、短期文件链接、租户字段、SSRF 防护 |
| 审计性 | 独立审计日志表、结构化事件、文件哈希、差异记录 |
| 可追溯性 | 文档版本、chunk、页码、矩阵 source 字段、证据卡片 |
| 可靠性 | 异步任务、任务状态机、幂等键、失败重试 |
| 性能 | 数据库索引、分页/虚拟滚动预留、API 不阻塞长任务 |
| 可修改性 | 适配器层、规则热加载、LLM Provider 抽象、存储抽象 |
| AI 可信度 | 来源约束、低置信度待确认、事实性校验、人工确认 |
| 可运维性 | 健康检查、结构化日志、任务状态、错误原因可见 |

## 7. 后续复审点

建议在以下时间点复审效用树：

1. MVP-v0.5 数据模型设计完成后。
2. 文件下载和解析任务跑通后。
3. 合规矩阵第一版真实数据展示后。
4. MVP-v1.0 增加 RAG、章节生成、规则包和助手能力前。
5. SaaS 多租户对外试用前。
