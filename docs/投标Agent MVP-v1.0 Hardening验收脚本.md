# 投标 Agent MVP-v1.0 试用前 P0 验收脚本

> 更新时间：2026-05-20
> 目标：在没有真实客户数据前，使用固定黄金样本反复验证 MVP1.0 是否已经达到受控试用标准。
> 范围：黄金样本回归、矩阵拆分质量、异步/失败态、提交前核验、版本风险、证据可信度、审批/导出阻塞和审计复盘。

## 1. 验收口径

MVP1.0 试用前 P0 不新增净化产品选型、图纸、技术标核心章节、多 Agent、报价、OCR 或自动提交。验收重点是系统能不能稳定提示风险、防止漏项，并让业务人员知道下一步该处理什么。

通过标准：

| 能力 | 通过口径 |
| --- | --- |
| 提交前核验 | 工作台能显示 `pass` / `warn` / `block`，并列出阻塞项和建议动作 |
| 版本过期提醒 | 人工发布新解析版本后，旧矩阵能提示“矩阵已过期” |
| 矩阵处理队列 | 合规矩阵能按 P0/P1/P2/P3 推荐顺序处理 |
| 证据推荐解释 | 证据检索结果能说明推荐原因、命中词和资料状态 |
| 草稿事实风险 | 草稿中无法验证事实能进入提交前核验并在草稿页提示 |
| 关键字段确认 | 工作台能编辑项目/标段关键字段，缺失字段会在核验区提示 |
| 审批阻塞原因 | 审批任务能展示创建时的核验快照、阻塞摘要和风险接受说明 |
| 导出与审计 | Word/Excel 可生成；阻塞状态导出 Word 必须填写说明并标记为内部草稿 |
| 黄金样本回归 | `mvp1-golden` 能验证净化样本矩阵、证据、preflight、审批和导出主链路 |
| 矩阵质量门槛 | 净化运维公告规则兜底抽取无重复、无标题/联系信息污染，并拆出关键资格项 |

## 2. 黄金演示样本

默认使用新增净化方向脱敏样本完成回归：

- 演示项目：`洁净车间净化设备采购与安装项目`
- 招标文件：`洁净车间净化设备采购与安装招标文件.pdf`
- 企业资料：产品目录、检测报告、技术方案，以及过期资质和草稿承诺材料
- 矩阵项：资格要求、强制响应项、技术响应项、评分项、截止时间风险
- 故意保留的风险：强制项缺证据、高风险待确认、技术响应待确认、资料过期/草稿状态

原 `智慧园区弱电工程投标` 样本继续保留，用于通用回归和兼容性测试。

## 3. 10 分钟演示路径

这条路径用于客户演示和内部试用前复核。演示时不强调“自动投标”，只强调“少漏项、少翻文件、少编错、可追溯”。

| 分钟 | 操作 | 预期展示 |
| ---: | --- | --- |
| 0-1 | 进入 `洁净车间净化设备采购与安装项目` | 工作台展示流程步骤和提交前核验 `block` |
| 1-2 | 打开文件解析，搜索“检测报告”或“洁净等级” | 能定位来源分块，说明矩阵有原文来源 |
| 2-4 | 打开合规矩阵，开启推荐处理排序 | P0/P1 风险项排在前面，技术响应项有独立标签 |
| 4-6 | 打开证据绑定，搜索并绑定检测报告 | 推荐原因、命中词、资料状态可见，缺证据数量下降 |
| 6-7 | 查看技术响应页 | 只预览技术/评分要求，不承诺生成技术标核心章节 |
| 7-8 | 尝试导出 Word | 阻塞状态必须填写风险接受说明，导出标记为内部草稿 |
| 8-9 | 创建提交确认审批 | 阻塞状态必须填写说明，审批任务保留 preflight 快照 |
| 9-10 | 查看审计日志 | 能看到证据绑定、导出、审批和风险说明 |

## 4. 手工验收步骤

1. 打开首页，进入 `洁净车间净化设备采购与安装项目` 工作台。
2. 查看“提交前核验”面板，确认能看到总体状态、阻塞项和建议动作。
3. 打开“项目关键信息”，修改或确认招标人、预算/限价、投标截止时间和标段名称，确认审计日志出现 `project.updated` / `section.updated`。
4. 进入“文件解析”，使用解析分块搜索定位“检测报告”或“洁净等级”。
5. 人工修正一段解析文本并发布新版本。
6. 回到“合规矩阵”，确认出现“矩阵已过期，建议基于最新解析版本重新生成”。
7. 点击重新生成矩阵，确认过期提醒消失或过期数量下降。
8. 打开“推荐处理”排序，确认 P0/P1 项排在普通响应项前面。
9. 选择缺证据矩阵项，打开证据绑定抽屉。
10. 检索企业资料，确认候选资料显示匹配度、推荐原因、命中词和资料状态。
11. 绑定一条合适证据，确认提交前核验中的缺证据数量下降。
12. 生成或打开商务/资格草稿，确认章节顶部显示事实校验状态。
13. 人工输入一个无法验证的证书编号并保存，确认草稿被标记为待确认事实。
14. 尝试导出 Word，确认系统要求填写风险接受说明；填写后可导出内部草稿，导出记录包含 preflight 快照。
15. 创建提交确认审批任务，若仍存在阻塞项，确认必须填写风险接受说明。
16. 审批通过高风险任务时，确认弹窗再次展示阻塞摘要并要求填写处理意见。
17. 查看审计日志，确认矩阵、证据、草稿、审批、导出和风险说明等关键动作有记录。

完整回归：


黄金样本 P0 快速回归：

```bash
make mvp1-golden
```

- 前端构建应通过；Vite 可能继续提示 chunk 体积较大，这是现有单页应用体积警告，不影响本轮 Hardening 验收。
- 黄金样本回归应覆盖净化样本项目、文件版本、矩阵、技术响应、证据推荐、preflight、审批阻塞和 Word 内部草稿快照。
- 净化运维公告规则兜底测试应验证拆分到最小粒度、无重复项、无公告标题/联系信息污染。

## 6. 失败记录口径

试用前验收出现失败时，不直接以“功能不可用”粗略记录，而是按以下字段沉淀问题：

| 字段 | 说明 |
| --- | --- |
| 样本来源 | 黄金样本、构造样本、用户脱敏样本或真实样本 |
| 复现步骤 | 从哪个页面、哪个按钮、哪个输入触发 |
| 预期结果 | 按本验收脚本应出现的状态 |
| 实际结果 | 页面/API/导出/审计实际表现 |
| 严重级别 | P0 阻塞、P1 影响试用、P2 体验问题 |
| 业务影响 | 是否可能导致漏项、错证据、错版本、误导审批或重复操作 |
| 数据权限 | 是否涉及真实客户数据、敏感材料或不可外发信息 |
| 处理结论 | 修复、延后、文档说明或转入 v1.1 |

## 7. 不纳入本轮验收

- 净化设备产品选型。
- 投标示意图。
- 技术标核心章节生成。
- 多 Agent 编排。
- 报价测算。
- 自动报名、自动签章、自动提交。
- OCR 增强。
- 全行业规则包。
